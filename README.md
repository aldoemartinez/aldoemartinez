### 🧠 Filosofía de Desarrollo
Mi enfoque se aleja de la sobrecarga de dependencias modernas para priorizar la **eficiencia, la velocidad y la resiliencia**, adaptados a la realidad de conectividad de América Latina.
- **Vanilla & Lightweight:** PHP puro, HTML5 semántico, Tailwind y Alpine.js. Cero frameworks pesados innecesarios.
- **Offline-First & Mobile-First:** Software diseñado para funcionar incluso cuando la red falla.
- **Soberanía Tecnológica:** Control total del stack, desde la lógica de negocio hasta la infraestructura (Nginx, Cloudflare, DigitalOcean).
